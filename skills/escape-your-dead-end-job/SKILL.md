# Escape your dead-end job

Small, realistic upgrades — not “quit and become a founder.”

## Tools
- `get_market_overview` for current field vs 1–2 adjacent fields
- `search_jobs` for step-up titles
- `get_job_details` / `get_job_keywords` for top picks

## Workflow
1. Capture current title, pay vibe, what they hate (hours, boss, standing, customers, nights).
2. Propose 3 exit ramps: same industry better employer, adjacent title, slightly different industry with transferable skills.
3. Search live roles for each ramp near them / remote if needed.
4. Rank by escape value vs risk.

## Output
**Stay slightly longer vs leave this month** framing + concrete apply list.
