# Quick jobs hiring now

## Tools
`search_jobs` with `posted_within_days: 7` (or 1–3 if “today/ASAP”), everyday titles, local if known.

## Workflow
Bias toward roles that start soon / high turnover. Skip multi-round FAANG-style unless asked.

## Output
**Apply this week** list with posted freshness called out.
